Wave field OFF · Physical dispersion available

The wave overlay visualises a regular sea state. When enabled, an educational wave-induced roll moment is added according to wave height, heading and period. This supports classroom exploration, but it is not a vessel-specific RAO or seakeeping model.

Physics consistency: Physical Wave mode solves ω² = gk tanh(kh) using water depth, then derives λ and phase celerity. Manual mode retains c = λ/T. Enhanced roll dynamics add quadratic damping; coefficients remain teaching inputs unless vessel data are supplied.
Environment: calm · no steady environmental heeling moment
Teaching model: wind uses quadratic aerodynamic pressure and a user-editable projected area/heeling lever. Current uses quadratic hydrodynamic drag for a stationary/moored or current-relative vessel. Rain and visibility are visual/operational factors only and do not directly create restoring or heeling moment.
